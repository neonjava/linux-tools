# linux-tools

Small tools I use on my Linux desktop. Each one has its own folder with install instructions.

## Tools

| Tool | What it does | Desktops |
| --- | --- | --- |
| [hdmi-auto-mirror](hdmi-auto-mirror/) | Mirrors your screen and audio to an HDMI display or TV when it's connected | Hyprland, GNOME |

## Get them

```sh
git clone https://github.com/neonjava/linux-tools.git
cd linux-tools
```

Then open the folder of the tool you want and follow its README.
